# Security Policy

## Reporting a vulnerability

Please **don't open a public issue** for security problems.

Report them privately through GitHub: on this repository, go to **Security → Report a vulnerability**. Include:

- what the problem is and what an attacker could do with it
- the steps to reproduce it, and the app version (Settings → App updates)
- any proof of concept, if you have one
  You'll get a reply as soon as possible. Please give a reasonable chance to release a fix before disclosing it publicly.

## Supported versions

Only the latest release receives security fixes. The app updates itself from 1.2.1 on.

## Scope

In scope: the Android app in this repository, including how it stores and sends your FDV sign-in, handles sign-in redirects, downloads and installs updates, and reads and writes files.

Out of scope: FlyDelta Virtual's website and API, SimBrief, and GitHub. Report problems with those to their owners.
